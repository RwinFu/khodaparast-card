# کارت ویزیت NFC برای اندروید

این برنامه یک تگ NFC Forum Type 4 فقط‌خواندنی را شبیه‌سازی می‌کند و لینک کارت را به صورت یک رکورد NDEF از نوع URL در اختیار گوشی دریافت‌کننده می‌گذارد. خودِ وب‌سایت نمی‌تواند شبیه‌سازی NFC انجام دهد.

## استفاده

1. گوشی فرستنده باید Android 6.0 یا جدیدتر، NFC و قابلیت Host Card Emulation داشته باشد. NFC را روشن کنید.
2. برنامه را باز کنید، گوشی را باز نگه دارید و **فعال‌کردن NFC** را بزنید.
3. آنتن NFC گوشی دیگر را به پشت گوشی خود نزدیک کنید. محل آنتن در مدل‌های مختلف فرق می‌کند. در گوشی دریافت‌کننده NFC و صفحه باید روشن باشند.
4. بسته به گوشی، گیرنده باید روی اعلان لینک بزند. عملکرد و پشتیبانی از تگ شبیه‌سازی‌شده در همهٔ گوشی‌ها یکسان نیست؛ کد QR در برنامه به‌عنوان جایگزین موجود است.
5. با خروج از برنامه یا لمس **پایان اشتراک‌گذاری**، اشتراک NFC غیرفعال می‌شود.

برنامه فقط لینک عمومی `https://rwinfu.github.io/khodaparast-card/?card=1` را ارسال می‌کند و مجوز اینترنت ندارد. سرویس به درخواست‌های NFC فقط وقتی برنامه فعال است پاسخ می‌دهد.

## ساخت نسخهٔ آزمایشی

با JDK 17 و Android SDK شامل platform 35:

```sh
cd android-nfc
./gradlew testDebugUnitTest assembleDebug
```

خروجی `app/build/outputs/apk/debug/app-debug.apk` نسخهٔ آزمایشی امضاشده با کلید debug است، نه نسخهٔ منتشرشده در Play Store. کلید debug ماشین‌های ساخت ممکن است متفاوت باشد؛ برای نصب نسخهٔ ساخته‌شده با کلید دیگر، ابتدا باید نسخهٔ آزمایشی قبلی حذف شود. عملکرد NFC باید روی گوشی‌های واقعی آزموده شود.
